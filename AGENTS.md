# WikiGames

- Monorepo npm con `apps/web` y `packages/catalog`; no requiere dependencias externas.
- Ejecutar `npm run dev` para servir la web en `http://localhost:3000`, `npm run build` para la salida estática y `npm test` para verificar filtros y datos.
- El catálogo de ejemplo está en `packages/catalog/src/index.js`. La web importa ese mismo módulo mediante `/catalog/index.js` en desarrollo y en la compilación.
- La base SQLite usa `node:sqlite` y está en `apps/web/data/wikigames.sqlite` (ignorada por Git). `library_items` guarda favoritos; no importar el antiguo `localStorage`, cuya clave `wikigames.library.v1` elimina la web. `local_games` guarda el inventario de E: y G:; `excluded_local_games` evita reimportar entradas eliminadas desde la web. Nunca borrar archivos físicos de esas unidades al eliminar una ficha.
- Mantener los textos de la interfaz en español. No incluir credenciales ni datos personales en el repositorio.
- En este equipo, PowerShell bloquea `npm.ps1`; ejecutar los scripts con `npm.cmd`.
- En Windows se puede iniciar la web directamente con `start.cmd`; queda disponible en `http://localhost:3000` y no en la URL de Herd.
- `apps/web/steam.mjs` consulta el endpoint público de detalles de Steam Store, con caché en memoria y datos locales como reserva. Si existe `STEAMGRIDDB_API_KEY`, consulta la API oficial de SteamGridDB desde el servidor para portadas verticales; la clave nunca llega al navegador. En ausencia de portada de SteamGridDB se usa la CDN de Steam. SteamDB se enlaza, pero no se consulta automáticamente porque no tiene API pública y prohíbe el scraping.
- El usuario tiene juegos en E: y G: y autorizó importar sus fichas a SQLite. `apps/web/inventory.mjs` escanea rutas concretas de Switch, Wii y Wii U en solo lectura. La importación inicial añadió 146 fichas (63 Switch, 30 Wii, 53 Wii U) el 2026-10-19. Repetir con `npm.cmd run import:local` o desde **Mis discos → Actualizar discos**. El disparador SQLite excluye futuras importaciones de fichas eliminadas, incluso si se borran directamente con SQL. No se copian ni modifican archivos de E: o G:.
- `npm.cmd run covers:sync` asocia carátulas a `local_games.cover_url`: Wii local desde `G:\WII\config\images`, y GameTDB para las demás con coincidencia de título y comprobación HTTP. La web sirve las portadas Wii desde su ruta original mediante `/api/local-games/:id/cover`. El 2026-10-19 se asociaron 118 de 146; 28 no tenían coincidencia fiable o imagen disponible. Las carpetas de iconos de Eden y Yuzu estaban vacías; Ryujinx tampoco tenía imágenes reutilizables en `AppData\Roaming\Ryujinx` ni junto a su ejecutable.
- En **Mis discos**, la portada y el título abren una ficha local. La opción de eliminar está dentro de la ficha y usa `confirm()` antes de llamar a DELETE; se cierra la ficha tras borrarla. Las portadas locales usan `object-fit: contain` para evitar recortes.
- `local_games.is_favorite` e `is_completed` guardan favoritos y juegos pasados, visibles en filtros por plataforma/estado. Los favoritos locales aparecen también en **Mi biblioteca**. `local_game_media` guarda enlaces de imagen/vídeo por juego; API GET/POST/DELETE `/api/local-games/:id/media` y PATCH `/api/local-games/:id` para estados. La eliminación de juego borra sus enlaces por clave foránea.
- `apps/web/scene.mjs` consulta los feeds públicos de YouTube de canales de SCENE/juegos elegidos entre la lista facilitada; la sección SCENE muestra novedades, con caché en memoria de 20 minutos. Resuelve el ID de canal desde la página pública con `?ucbcb=1` y lee `feeds/videos.xml`, sin credenciales. Si YouTube cambia la página o bloquea solicitudes, el feed puede quedar vacío; los enlaces a canales permanecen.
- `apps/web/steam.mjs` también devuelve hasta seis capturas y dos vídeos MP4 verificados por juego destacado cuando Steam Store ofrece esos datos; la ficha los muestra sin guardarlos en SQLite.
- `apps/web/ports.mjs` consulta `https://gamewave.digital/ports/catalog.json` para enlazar proyectos de ports en las fichas. Coincide por `gameNames` exacto normalizado, excluye entradas desactivadas y `community_android_sheet`, limita a cinco enlaces por juego y mantiene caché de 24 horas. Excepción explícita: la ficha local `Super Mario Galaxy 1-2` enlaza al port de `Super Mario Galaxy` (juego 1), nunca al 2. El bloque de ports está justo bajo el título y la tarjeta local muestra distintivo. La API `/api/ports` devuelve solo coincidencias de los juegos actuales. Si GameWave falla, las fichas siguen sin estos enlaces; no se guarda nada en SQLite.
